Bloom – Daily Wellness Tracker

Bloom is a visually calming, collage-inspired web app designed to help students track their daily wellness and cultivate healthier routines in a peaceful online space. Built for a first-semester web development syllabus, Bloom demonstrates mastery of foundational HTML and CSS concepts while delivering a beautiful and accessible user experience.

Features

- Gradient Navigation & Footer: Navigation and footer bars feature soft, pastel gradients inspired by the Bloom project’s flower motif.
- Custom Logo and Theme Colors: The layout and color scheme harmonize with the Bloom collage logo, creating a cohesive and premium visual identity.
- Responsive Layout: All sections are responsive, with Flexbox and CSS Grid used for navigation, tips display, and content organization.
- Daily Wellness and Gratitude Journals: Seamlessly designed forms allow logging of sleep, hydration, mood, daily activities, and gratitude reflections—styled for clarity and ease of input.
- Weekly Progress Summary: The summary table uses modern border-radius, soft pastel backgrounds, subtle accent colors, and aesthetic fonts for a clean and engaging look.
- Decorative Quote Images: Motivational quotes appear as playful “falling” images beside wellness tables, enhancing engagement and positivity.
